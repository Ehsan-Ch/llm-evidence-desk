Expected facts and evaluation checks


System design
A small, inspectable RAG pipeline
Approved current passagesBM25 retrievalLocal LLMQuote validation
Only exact source quotations are rendered as evidence. Unknown source IDs, modified quotations, malformed output, and incomplete generation are rejected. Archived and unapproved documents are excluded before retrieval.
Approval is manually supplied metadata. It does not detect malicious content inside a mistakenly approved document. This system does not verify semantic relevance, completeness, or truth.


Evaluation boundaries
Useful evidence, limited claims
Twenty hand-authored questions probe one fictional handbook. Six separate development questions select the retrieval depth. No fine-tuning or external judge is used.
A task check requires the expected source and fact text, or an explicit abstention when information is missing. It is a narrow fixture check, not a general measure of answer quality. Both adversarial examples are illustrative; they do not establish prompt-injection resistance.
For new questions, start the local app with evidence-desk serve. This downloaded report only replays the saved model run.
